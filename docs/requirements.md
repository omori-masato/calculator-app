# 電卓アプリケーション 要件定義書

**バージョン**: 1.0.0  
**最終更新日**: 2025-09-03  
**ステータス**: ドラフト  

## 1. プロジェクト概要

### 1.1 目的と背景

見積もり作業や日常計算において、過去の計算結果を参照できない課題と、計算途中で別の計算を一時的に行えない課題を解決する電卓アプリケーションを開発する。計算ミスの削減と見積もり時間の5分短縮を実現し、効率的な計算環境を提供する。

### 1.2 ターゲットユーザー

- **日常計算ユーザー**: 基本的な計算を行う一般ユーザー
- **会計作業者**: 見積もり作成や会計業務を行うビジネスユーザー
- **見積もり作成者**: 複数の計算を組み合わせて見積もりを作成する作業者

### 1.3 核となる機能と価値

以下は、プロジェクトの本質的価値を提供するために「絶対に必要」な機能です。各機能は「この機能がないとプロジェクトの目的達成が不可能になる」という基準で厳選されています。

- **基本計算機能**: 四則演算（+、-、×、÷）の実行 - *この機能がないと電卓としての基本価値を提供できない*
- **計算履歴機能**: 過去10件の計算結果を記憶・参照 - *この機能がないと過去の計算結果参照という主要課題が解決できない*
- **一時保存機能**: 計算途中で2つまでの計算を一時保存 - *この機能がないと計算途中での別計算実行という主要課題が解決できない*
- **消費税計算機能**: 10%の消費税計算と割戻し計算 - *この機能がないと会計作業での利便性という価値提案ができない*

## 3. ページ詳細

このセクションでは、各ページの詳細と、それらに含まれる画面要素について説明します。

### 3.1 公開ページ

#### 3.1.1 メイン計算ページ (P-001)
**モックアップ**: [calculator.html](/mockups/calculator.html)

**ページ概要**: 基本計算、消費税計算、一時保存機能を統合したメイン計算画面

**含まれる画面要素**:
- ディスプレイエリア: 計算式と結果の統合表示（28px、右寄せ）
- 数字ボタン: 0-9の数字入力（3×3+0ボタンの標準配置）
- 演算子ボタン: +、-、×、÷、=の演算処理
- 制御ボタン: C（クリア）、⌫（一文字削除）
- 一時保存エリア: 2スロット（Save1/Recall1、Save2/Recall2）
- 税計算ボタン: 税込（+10%）、税抜（-10%）の独立配置

**状態と動作**:
- 初期状態: ディスプレイに「0」表示、全メモリスロット空
- 数字入力時: 連続入力で数値構築、結果表示後は新規入力開始
- 演算処理時: 計算式をディスプレイに表示、=押下で計算実行
- エラー状態: 無効な計算式で「エラー」表示、次の入力でリセット
- 一時保存時: 現在値をスロットに保存、視覚的に保存状態を表示
- 税計算時: 現在表示値に対して即座に税込/税抜計算を実行
- キーボード対応: 数字、演算子、Enter、Escape、Backspaceキーに対応

**データとAPI**:
- 計算履歴モデル: { id: string, expression: string, result: number, timestamp: Date, type: 'basic' | 'tax-inclusive' | 'tax-exclusive' }
- 一時保存モデル: { slot1: number | null, slot2: number | null }
- `POST /api/calculations` → 計算実行と履歴保存
  - リクエスト: { expression: string, type: 'basic' | 'tax-inclusive' | 'tax-exclusive' }
  - 成功: { result: number, historyId: string }
  - エラー: [400] 計算式エラー、[500] 数値オーバーフロー
- ローカルストレージ: 計算履歴の永続化（最大10件）

#### 3.1.2 計算履歴ページ (P-002)
**モックアップ**: [history.html](/mockups/history.html)

**ページ概要**: 過去10件の計算履歴を効率的に表示し、ワンクリックで結果再利用を可能にする

**含まれる画面要素**:
- 履歴ヘッダー: ページタイトル「計算履歴」、全削除ボタン
- フィルターセクション: 計算種別フィルター（すべて/基本/税込/税抜）
- 履歴リスト: スクロール可能な履歴項目一覧
- 履歴項目: 計算式、結果値、計算種別ラベル、相対時間表示
- 戻るボタン: メイン計算ページへの直接遷移

**状態と動作**:
- 初期表示: 全履歴を新しい順で表示、サンプルデータ自動生成
- 履歴項目ホバー: 「クリックして使用」ヒント表示、視覚的強調
- 履歴選択時: 選択値をローカルストレージ経由でメイン画面に転送
- フィルタリング時: 計算種別による即座の絞り込み表示
- 空状態: 履歴なしの場合の案内メッセージ表示
- 相対時間更新: 1分ごとの自動更新（「3分前」→「4分前」）
- キーボード操作: Escapeキーでメイン画面に戻る

**データとAPI**:
- 履歴表示モデル: { id: string, expression: string, result: number, timestamp: Date, type: 'basic' | 'tax-inclusive' | 'tax-exclusive' }
- フィルター状態: currentFilter ('all' | 'basic' | 'tax-inclusive' | 'tax-exclusive')
- `GET /api/calculations/history` → 計算履歴取得
  - 成功: { history: CalculationHistory[] }
  - エラー: [500] データ取得エラー
- `DELETE /api/calculations/history` → 全履歴削除
  - 成功: { message: 'History cleared' }
  - エラー: [500] 削除処理エラー
- ローカルストレージ: 履歴データの永続化とページ間値転送

#### 3.1.3 統合計算ページ (P-003)
**モックアップ**: [unified-calculator.html](/mockups/unified-calculator.html)

**ページ概要**: 計算機能と履歴表示を横並びで統合し、ページ遷移なしで全機能を利用可能

**含まれる画面要素**:
- 左側計算セクション（60%）: ディスプレイ、数字ボタン、演算子、一時保存、税計算
- 右側履歴セクション（40%）: 履歴ヘッダー、フィルター、履歴リスト
- レスポンシブレイアウト: モバイルでは縦積み表示

**状態と動作**:
- 同時操作: 計算実行と履歴参照の並行処理
- リアルタイム連携: 新規計算時の履歴即座更新
- ワンクリック再利用: 履歴項目クリックで計算機に値設定
- 小数点精度管理: 8桁精度での丸め処理、税計算は2桁精度
- 履歴管理: 全削除機能、フィルタリング機能

**データとAPI**:
- 統合状態管理: 計算状態と履歴状態の同期
- リアルタイム更新: 計算実行時の履歴自動追加
- `POST /api/calculations` → 計算実行と履歴同時更新
- `GET /api/calculations/history` → 初期履歴取得
- `DELETE /api/calculations/history` → 履歴全削除

## 4. データモデル概要

モックアップから導出される主要データモデルを以下に示します。すべての型定義は`frontend/src/types/index.ts`と`backend/src/types/index.ts`で一元管理され、**両ファイルは完全に同期された状態で管理**されます。

### 4.1 主要エンティティ

| エンティティ名 | 主な属性 | 役割・用途 | データ永続化 |
|------------|----------|----------|------------|
| **CalculationHistory** | id, expression, result, timestamp, type | 過去10件の計算履歴を管理。フィルタリング・再利用機能を提供 | ローカルストレージ（10件制限） |
| **TemporarySave** | slot1, slot2 | 計算途中の値を2スロットで一時保存 | セッションのみ（ブラウザ閉鎖で消去） |
| **CalculatorState** | displayValue, currentExpression, lastResult, isResultDisplayed | 計算機の現在状態を管理 | セッションのみ |

### 4.2 計算タイプ定義

```typescript
type CalculationType = 'basic' | 'tax-inclusive' | 'tax-exclusive';
```

- **basic**: 四則演算（+、-、×、÷）
- **tax-inclusive**: 消費税込み計算（元の値 × 1.1、小数点以下2桁で丸め）
- **tax-exclusive**: 消費税抜き計算（元の値 ÷ 1.1、小数点以下2桁で丸め）

### 4.3 API エンドポイント仕様

| エンドポイント | メソッド | 用途 | リクエスト型 | レスポンス型 |
|-------------|---------|------|-----------|-----------|
| `/api/calculations` | POST | 計算実行と履歴保存 | CalculationRequest | CalculationResponse |
| `/api/calculations/history` | GET | 計算履歴の取得 | - | HistoryResponse |
| `/api/calculations/history` | DELETE | 全計算履歴の削除 | - | HistoryClearResponse |

### 4.4 エラーハンドリング

```typescript
type CalculationErrorType = 
  | 'INVALID_EXPRESSION'    // 不正な計算式
  | 'DIVISION_BY_ZERO'      // ゼロ除算
  | 'OVERFLOW'              // 数値オーバーフロー
  | 'UNDERFLOW'             // 数値アンダーフロー
  | 'UNKNOWN_ERROR';        // その他のエラー
```

### 4.5 型定義同期の保証

- **同期原則**: `frontend/src/types/index.ts` ↔ `backend/src/types/index.ts` は必ず同一内容
- **変更ルール**: 一方を更新したら即座にもう一方も同じ内容で更新
- **API パス管理**: APIエンドポイントは型定義ファイル内の `API_PATHS` で一元管理
- **型ガード**: 実行時型検証のためのガード関数を提供

## 5. 特記すべき非機能要件

以下は標準的な実装方針から特に注意すべき点です：

- **履歴保存**: ブラウザローカルストレージを使用し、最大10件まで保存
- **一時保存**: セッション中のみ有効、ブラウザ閉鎖で消去
- **消費税率**: 10%で固定、将来的な税率変更に備えた設定可能な実装
- **計算精度**: 小数点以下の丸め誤差を考慮した適切な精度管理
